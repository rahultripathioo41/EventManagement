Event Management System
📌 Overview

The Event Management System is a web-based application built using Spring Boot + Thymeleaf that allows efficient management of events, participants, and administrative tasks. It provides separate functionalities for Admin and Users, ensuring a smooth and role-based event management process.

✨ Features
👨‍💼 Admin Features

Add, update, and delete events

Manage participants and their registrations

View daily summary of event activities

Role-based access for secure admin control

👤 User Features

User registration and login with role-based authentication

View available events

Register for events

Manage personal event participation details

🛠️ Technologies Used

Backend: Spring Boot (MVC + Security)

Frontend: Thymeleaf, Bootstrap, JavaScript (AJAX)

Database: MySQL with Hibernate (JPA)

Server: Apache Tomcat

Version Control: Git & GitHub

📊 Project Highlights

Secure role-based authentication & authorization with Spring Security

Dynamic pages with Thymeleaf fragments (navbar, footer, layouts)

AJAX integration for smooth user experience (e.g., form submissions without page reload)

Admin-only access to analytics and event summary

Mobile-responsive UI using Bootstrap
